I build reproducible data-analysis and machine-learning workflows in **Python and R**, with work spanning predictive modelling, representation learning, dimensionality reduction, anomaly detection, healthcare analytics, business analytics and geospatial analysis.

My approach is grounded in quantitative problem-solving: define the problem clearly, validate assumptions, keep training and evaluation boundaries clean, and communicate results in a way that remains useful beyond the model itself.

## How I work

- Build reproducible workflows rather than one-off analyses.
- Keep preprocessing and validation boundaries explicit to avoid data leakage.
- Start with interpretable baselines before adding unnecessary complexity.
- Document assumptions, limitations and data requirements clearly.
- Treat communication and reproducibility as part of the technical work.
